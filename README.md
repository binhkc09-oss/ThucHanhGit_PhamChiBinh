## Mô tả dự án
Dự án này lưu trữ các bài thực hành Git cá nhân của Phạm Chí Bình.
## Kỹ thuật đã thực hiện
- Quản lý phiên bản cục bộ, nhánh (branch) và hợp nhất (merge).
- Làm việc với remote repository trên GitHub qua SSH.
- Khôi phục lịch sử, xử lý xung đột và sử dụng submodule.
